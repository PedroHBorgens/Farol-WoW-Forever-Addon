# CurseForge images / Imagens do CurseForge

Promotional **illustrations** of Farol's features (1280×720, captions in English and Portuguese).
They are faithful drawings of the add-on's windows, not in-game screenshots, so each image carries a small
"Illustration · Ilustração" label.

**Ilustrações** de divulgação das funções do Farol (1280×720, legendas em inglês e português). São desenhos
fiéis das janelas do addon, não prints do jogo; por isso cada imagem tem o selo "Illustration · Ilustração".

## Regenerate / Gerar de novo

The pages are HTML generated by `make_pages.py` and captured with Playwright (`shoot.js`):

```
python3 assets/curseforge/make_pages.py   # writes the .html pages next to the script
node assets/curseforge/shoot.js           # renders each .html to .png (1280×720)
```

Then rename the PNGs with the `farol-` prefix. The generated `.html` files are not versioned.
